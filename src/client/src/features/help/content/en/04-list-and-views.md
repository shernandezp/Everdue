# The list, filters and saved views

The board shows what is in front of you. **List** shows everything, and lets you cut it any way you
need — including work from months ago.

It is also where every report number lands: click a figure on a report and you arrive here, already
filtered to exactly the work behind it.

## Filtering

The filter card sits above the table. Every filter narrows the list; several filters apply together.

| Filter | Use it to find |
|---|---|
| **Search** | Words in a title or description |
| **Owner** | One person's work |
| **Entity** | Everything about one customer, machine, supplier… |
| **Department** | Everything one team executes |
| **Status** | One or several states at once — e.g. *Missed* + *On hold* |
| **Reason** | Work parked for one particular reason |
| **Overdue only** | Anything past its due date and unfinished |
| **Show cancelled** | Cancelled tasks, which are hidden by default |

**Clear** removes every filter at once.

> Your filters live in the address bar, so you can copy the link and send it to a colleague. They will
> see the same list — subject to what their account is allowed to see.

## Saved views

A filter combination you set up every Monday is worth saving.

1. Set the filters you want.
2. Open **Saved views → Save this view**.
3. Give it a name you will recognise: *"Acme, missed and on hold"*.

Afterwards, pick it from the same menu to apply it. Saving with an existing name replaces it, and the
bin icon deletes one. Saved views are **personal** — nobody else sees yours.

## Selecting several items at once

The checkbox at the left of each row selects it. As soon as something is selected, an action bar
appears above the table:

| Action | What it does |
|---|---|
| **Complete** | Completes everything selected. Items whose period has ended land as *completed late* |
| **Hand over** | Changes the owner of everything selected |
| **Reschedule** | Moves the due date of everything selected, with an optional note |
| **Clear** | Drops the selection |

Bulk actions obey exactly the same rules as one-at-a-time actions, so a refusal is possible: you get a
summary like *"28 updated, 2 refused"* with the first reason, rather than a silent partial change.

## Exporting to a spreadsheet

**Export CSV** downloads exactly the rows on screen, with the filters you have applied. The file
matches the screen by construction: it runs the same query.

- It opens correctly in Excel, accents included.
- Over 50,000 rows, Everdue refuses and asks you to narrow the filters. It will never hand you a file
  that is quietly incomplete.

## Reading the table

| Column | Notes |
|---|---|
| Title | With a checklist badge if the item has steps |
| Status | Plus *Overdue* and hold badges where they apply |
| Entity | What the work is about, or — |
| Owner | Who it belongs to now |
| Due | Red when the date has passed and the work is unfinished |

Click any row to open the item's detail panel.

## A worked example

*"Which of Acme's work did we miss in the last few months, and who was it?"*

1. **Entity** → Acme.
2. **Status** → Missed.
3. Read the **Owner** column.
4. Save it as *"Acme misses"* if you will ask again next month.
5. **Export CSV** if somebody wants it in a spreadsheet.
